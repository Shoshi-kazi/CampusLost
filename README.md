# CampusLost

**A Campus Lost and Found Android Application**

CampusLost is an Android application designed to help university students report and find lost or found belongings on campus.

## Features

- User Registration and Login
- Firebase Authentication
- Add Lost and Found Items
- View Item Details
- Edit and Delete Own Posts
- Search Items
- Filter by All, Lost, and Found
- User Profile
- Logout
- Shake Sensor Integration
- Voice Assistant for Basic Navigation

## Technologies Used

- Java
- XML
- Android Studio
- Firebase Authentication
- Firebase Realtime Database
- RecyclerView
- Android Sensor API
- Android Speech Recognition and Text-to-Speech

## Application Screens

- Splash Screen
- Login Screen
- Registration Screen
- Home Screen
- Add/Edit Item Screen
- Item Details Screen
- Profile Screen

## Requirements

- Android Studio
- Java Development Kit
- Android SDK
- Firebase Project

## Setup

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Configure your own Firebase project.
4. Add the required `google-services.json` file inside the `app` directory.
5. Sync Gradle.
6. Run the application on an Android device or emulator.
