# CampusLost

**A Campus Lost and Found Android Application**

CampusLost is an Android application designed to help university students report, search, and find lost or found belongings on campus.

## Features

- User Registration and Login
- Firebase Authentication
- Remember Me using SharedPreferences
- Add Lost and Found Items
- View Detailed Item Information
- Edit and Delete Own Posts
- Search Items by Title, Description, and Location
- Filter Items by All, Lost, and Found
- Real-time Item Updates using Firebase Realtime Database
- User Profile
- Navigation Drawer
- Dashboard with Item Summary
- Image Selection from Gallery
- Capture Photos Using Camera
- Cloudinary Image Upload
- Shake Sensor Integration
- Voice Assistant for Basic Navigation
- Share Item Information Using Android Intent
- Input Validation and Error Handling
- Updated UI Design and Custom App Icon

## Setup

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Configure your own Firebase project.
4. Enable Email/Password Authentication in Firebase.
5. Create a Firebase Realtime Database.
6. Add your `google-services.json` file inside the `app` directory.
7. Configure your own Cloudinary upload settings.
8. Sync Gradle.
9. Run the application on an Android device or emulator.
